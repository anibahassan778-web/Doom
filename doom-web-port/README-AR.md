# DOOM 1.10 — منفذ متصفح WebAssembly

هذا المشروع يحوّل مصدر **Linux DOOM 1.10** الموجود في `source/DOOM-master` إلى تطبيق متصفح باستخدام Emscripten. منطق اللعبة والرسم الأصليان يبقيان في C؛ ويُستخدم Canvas فقط لعرض إطار 320×200، بينما يتولى Web Audio تشغيل مؤثرات الصوت.

## ما يعمل في هذا المنفذ

- محرك DOOM الأصلي 1.10 ومصيّر software renderer ذي 8-bit palette.
- عرض Canvas بدقة 320×200 مع تكبير nearest-neighbour.
- لوحة المفاتيح والفأرة.
- أزرار لمس أساسية للهاتف.
- مؤثرات صوتية عبر Web Audio.
- اختيار ملف IWAD من الجهاز وكتابته محلياً في نظام ملفات Emscripten.

## ما لا يتضمنه المصدر الأصلي

الأرشيف الأصلي لا يحتوي على `DOOM.WAD` أو `DOOM2.WAD` أو ملفات المراحل والرسوم. هذه ملفات بيانات منفصلة وليست جزءاً من شيفرة المحرك. اختر ملف IWAD تملكه قانونياً عند تشغيل الصفحة. لا تُضمّن ملفات DOOM التجارية في هذا المشروع.

الموسيقى الخلفية والشبكات متعددة اللاعبين غير مدعومتين في هذا المنفذ؛ هذا الإصدار من Linux DOOM نفسه كان يستخدم واجهة موسيقى فارغة، والشبكة هنا معطّلة لصالح اللعب الفردي.

## بناء نسخة الويب

1. ثبّت Emscripten SDK من الدليل الرسمي: <https://emscripten.org/docs/getting_started/downloads.html>
2. فعّل بيئة Emscripten في الطرفية (`emsdk_env.sh`).
3. من مجلد المشروع نفّذ:

   ```bash
   ./build-web.sh
   ```

ينتج البناء:

- `web/doom.js`
- `web/doom.wasm`

4. شغّل خادماً محلياً من مجلد المشروع:

   ```bash
   ./serve.sh
   ```

5. افتح `http://localhost:8000`، اختر نوع IWAD الصحيح، ثم اختر ملف `.wad` واضغط «ابدأ اللعبة».

**مهم:** لا تفتح `index.html` مباشرة عبر `file://`. ملفات WebAssembly يجب أن تُقدَّم عبر HTTP/HTTPS.

## التحكم

- `W A S D` أو الأسهم: حركة/التفاف.
- `Ctrl`: إطلاق.
- `Space`: استخدام/فتح الأبواب.
- `Shift`: ركض.
- `Esc`: القائمة.
- الهاتف: استخدم أزرار اللمس الظاهرة أسفل الشاشة.

## ملاحظات البناء

- `build-web.sh` يتجاوز ملفات Linux الخاصة بـ X11 وOSS، ويستخدم ملفات backend الموجودة في `platform/`.
- شبكة اللعب الجماعي معطلة، ويُهيّأ محرك الشبكة كجلسة محلية ذات لاعب واحد.
- حلقة اللعبة عُدّلت إلى `emscripten_set_main_loop` كي لا تحجب واجهة المتصفح.
- لم أتمكن من إنتاج `doom.js` و`doom.wasm` في بيئة العمل هذه لأن `emcc` غير مثبت. المشروع يحتوي على ملفات المنفذ وسكربت البناء؛ يجب تنفيذ البناء في بيئة Emscripten.

## الترخيص

ملفات المصدر الأصلية ورخصتها مرفقة في `source/DOOM-master/`. التعديلات وملفات web backend الجديدة مضافة لهذا المنفذ بتاريخ 2026-11-08، مع الاحتفاظ بإشعارات وترخيص المصدر الأصلي.
